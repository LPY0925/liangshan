# 两山20年 — 生态文化数字展馆

## 作品概述

沉浸式数据新闻作品，以「绿水青山就是金山银山」理念提出20周年为背景，通过交互式网页叙事，展现中国生态文明建设的绿色变革历程。

作品融合滚动驱动动画、数据可视化、3D交互等现代 Web 技术，将宏大主题转化为可感、可知、可互动的数字体验。

**核心命题：** 绿水青山如何成为金山银山？生态价值如何被看见、被计算、被实现？

## 章节结构

1. 首页 — 序章引入
2. 超级周 — 生态文明建设历程
3. 翻轉立方體 — 3D交互展示
4. 三层时间变换 — 历史对比
5. 日月轮转 — 生态循环
6. 次页打字机 — 叙事呈现

## 技术栈

- HTML / CSS / JavaScript
- 3D 交互效果
- 滚动驱动动画
- 响应式设计

## 项目结构

- `common-controls.js`：统一维护章节目录、背景音乐、自动滚动和跨页过渡，章节页面只保留当前章节标记。
- `images/导航缩略图/`：目录使用的轻量 WebP 资源；高清原图仍保留在 `images/nav/`。
- 各章节的 `script.js`：只负责本章动画与数据交互，滚动动画在页面空闲或离开视口后会降低工作量。
- `工具/验证网页结构.mjs`：检查本地资源、章节锚点、重复 `id` 和内联脚本语法。

运行结构检查：

```powershell
node "工具/验证网页结构.mjs"
```

生成静态托管产物：

```powershell
node "工具/构建站点.mjs"
```
